# parking-lot-tracker

Parking Lot Tracker is a database driven application designed to store and analyze parking lot occupancy data

## Parking Overview

The application will allow users to import parking data from a CSV file and store the information in a database. Users will be able to analyze parking lot capacity and occupancy at different dates and times.

For testing, we plan to use the Parking Birmingham dataset from the UCI Machine Learning Repository.

## Planned Features

- Import parking data from CSV files
- Store parking lot and occupancy records in a database
- Calculate average parking lot occupancy
- Search and filter data by parking lot, date, and time
- Compare occupancy between different parking lots
- Display parking occupancy trends

## Dataset

Our initial test dataset is the Parking Birmingham dataset from the UCI Machine Learning Repository. It contains historical parking capacity and occupancy records with timestamps.
